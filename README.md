# ホワイトボード

テキスト中心の無限キャンバス。ブラウザだけで動く単一 HTML ファイルです。

会議の板書、アイデア整理、図面や写真への注釈を想定しています。文字入力を主、手書きを補助と位置づけているため、キーボードだけでも図を組み立てられます。

- ビルド不要。`index.html` をダブルクリックすれば開きます
- 外部の CDN・ライブラリ・フォントを一切参照しません。オフラインで完結します
- 描いた内容は JSON ファイルとして手元に保存します。サーバーへは何も送りません

---

## 公開する

### GitHub Pages に置く

1. リポジトリを作り、ルートに次の並びでファイルを置きます

   ```
   index.html
   manifest.json
   README.md
   icon/
     icon.svg
     icon-180.png
     icon-192.png
     icon-512.png
     icon-512-maskable.png
   ```

2. リポジトリの **Settings → Pages** を開き、Source を **Deploy from a branch**、Branch を **main / (root)** にします
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

ビルド手順はありません。パスはすべて相対指定なので、サブパス配信でも壊れません。

### 公開すると増える機能

`file://` で開いたときと違い、HTTPS で配信すると次が使えるようになります。

| 機能 | `file://` | HTTPS |
|---|---|---|
| 同じファイルへの上書き保存（Ctrl+S） | 不可 | 可（Chrome / Edge） |
| 自動バックアップ | 不可 | 可 |
| ホーム画面・デスクトップへの追加 | 不可 | 可 |

上書き保存と自動バックアップは File System Access API に依存します。この API は Chrome 86 以降・Edge 86 以降・Opera 72 以降で使え、Firefox と Safari では使えません。使えない環境では、保存は「ダウンロード」、読み込みはファイル選択になります。いまどちらで動いているかは、ステータスバーの保存状態（`board.json (上書き)` / `(書き出し)`）と、そこにカーソルを重ねたときの説明で分かります。

### ローカルファイルだけで使う

`index.html` 単体でも全機能のうち上表の 3 つを除いて動きます。この場合、HTML 先頭にある `apple-touch-icon` と `manifest` の 2 行は参照先が無いため、開発者コンソールに警告が出ます。気になる場合は削除してください。タブのアイコンは HTML に直接埋め込んであるので、削除しても表示されます。

## 画面の構成

| 場所 | 中身 |
|---|---|
| 上部バー | 元に戻す・やり直す、開く・保存、レイヤー、メニュー（≡） |
| ツール | 広い画面では左端の縦レール、狭い画面では下部のドック（入りきらない枠・直線・フレームは「その他」の中） |
| メニュー（≡） | テンプレート、グリッド・吸着・ガイド、テーマ、書き出し、名前を付けて保存、ヘルプ |
| 書式パネル | 図形を選ぶと出ます。色・サイズ・整列・重なり・複製・削除 |
| ズーム | 広い画面では右下、狭い画面では右上 |
| ステータスバー | 図形の数、グリッド・吸着・ガイドの状態、保存状態とファイル名。知らせることがあるときだけ通知が出ます |

## できること

### 図形

| 種類 | 作り方 |
|---|---|
| 文字 | 空白をダブルクリック、または `T` でドラッグして折り返し幅を指定 |
| 付箋 | `N` でクリックまたはドラッグ。文字が入りきらないと下に伸びます |
| 枠 | `R` でドラッグ |
| 直線・矢印 | `L` / `A` でドラッグ。Shift で 45 度刻み |
| 手書き | `P` でドラッグ |
| フレーム | `F` でドラッグ。範囲を指定して部分書き出しに使います |
| 画像 | クリップボードから `Ctrl+V` で貼り付け |

枠・矢印・画像・手書き・フレームには、図形に追従する文字を付けられます（選択して `Enter`、またはダブルクリック）。

**キーボードだけで置くこともできます。** ツールのキー（`T` `N` `R` `L` `A` `F`）を押してから `Enter` を押すと、その種類の図形が置かれます。何も無ければ画面の中央、既に図形があれば**全体の左端にそろえてその下**に置かれるので、`N` → `Enter` → 入力 を繰り返すと付箋が縦一列に並びます。手書きは「描く」操作なので対象外です。

### つなぐ

図形にカーソルを重ねると、中心と各辺の中点に接続点が出ます。そこからドラッグすると矢印が伸び、**空白で離すと同じ種類の図形が作られて矢印でつながります**。つないだ端点は、図形を動かしても大きさを変えても追従します。

キーボードでは、図形を選んで `Alt+Shift+方向キー` で同じことができます。

### そろえる

- **座標ガイド** — 移動中・大きさ変更中に、他の図形と端や中心がそろう位置で吸着し、根拠の線が出ます
- **等間隔ガイド** — 左右（上下）の相手との間隔が等しくなる位置、既にある間隔を延長する位置で吸着します
- **グリッド** — 間隔を 8〜80 から選び、吸着を切り替えられます
- **整列・等間隔配置** — 2 つ以上選ぶと書式パネルに出ます

### テンプレート

メニュー（≡）から定型のレイアウトを挿入できます。

| テンプレート | 中身 |
|---|---|
| ふりかえり（KPT） | Keep / Problem / Try の 3 列と、各列の空の付箋 |
| 2×2 マトリクス | 十字の軸、4 象限の枠、軸のラベル |
| 会議メモ | アジェンダ／決定事項／ToDo／保留 の 4 区画 |
| 図面注釈セット | 凡例の枠と、番号付きの注釈 5 個（矢印の先はどこにも繋がっていないので、図面の該当箇所へ端点をドラッグして繋ぎます） |

挿入したものは 1 つのフレームで囲まれるので、そのまま「フレームを書き出し」の対象になります。色はテーマに追従し、`Ctrl+Z` 一回で全体が消えます。既に図形があるときは、重ならないよう右隣に置かれます。

### 大きさを変える

図形を選ぶと四隅にハンドルが出ます。**複数選んだときは選択範囲全体の四隅**に出て、引くと選択中の図形がまとめて拡大・縮小されます（相対的な位置関係は保たれます）。文字サイズと線の太さは変わりません。

`Shift` を押しながら引くと、動かした向きの軸だけに固定されます（右へ動かせば横だけ、下へ動かせば縦だけ）。

### レイヤー

図形をレイヤーに分けられます。レイヤーごとに表示・非表示とロックを切り替えられ、非表示のレイヤーは書き出しにも含まれません。下敷きにした図面を固定して、その上に注釈を描く使い方ができます。

### テーマ

ダーク（既定）・深緑・製図・和紙の 4 つ。切り替えると既存図形の色も対応する色へ置き換わります。テーマは保存ファイルに記録されるので、開き直すと同じ配色で開きます。

### 書き出し

SVG と PNG に書き出せます。範囲は「全体 / 選択範囲 / フレーム」から選べます。フレームを指定すると、その矩形で切り取った画像になります。

## キーボード操作

アプリ内で `?` を押すと一覧が出ます。

| キー | 動作 |
|---|---|
| `V` `T` `N` `R` `L` `A` `P` `F` | 選択／文字／付箋／枠／直線／矢印／手書き／フレーム（選んだあと `Enter` で置く。手書きを除く） |
| `Tab` / `Shift+Tab` | 図形を順に選ぶ |
| 方向キー | 移動（`Shift` で大きく、グリッド吸着中は格子ぶん） |
| `Alt+方向キー` | 大きさを変える |
| `Alt+Shift+方向キー` | その向きに矢印と同じ図形を足す |
| `Enter` / `F2` | 選んだ図形の文字を編集。ツールを選んでいるときは `Enter` で図形を置く |
| `Ctrl+Enter` | 画面中央に挿入メニュー |
| `Delete` | 削除 |
| `Ctrl+方向キー` | 画面をスクロール |
| `+` `−` `0` `9` | 拡大／縮小／100%／全体を表示 |
| `Ctrl+A` `C` `X` `V` `D` | 全選択／コピー／切り取り／貼り付け／複製 |
| `Ctrl+[` `]` | 背面へ／前面へ（`Shift` 併用で最背面・最前面） |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す／やり直す |
| `Ctrl+S` / `Ctrl+O` | 保存／開く |
| `F6` | 上部バーへ移動（そこからは `Tab` で送る） |
| `Escape` | 解除・メニューを閉じる・キャンバスへ戻る |

## マウス操作

- ホイールでスクロール、`Ctrl+ホイール` で拡大縮小
- `Space+ドラッグ`、中ボタンドラッグ、右ドラッグでキャンバス移動
- 右クリックで挿入メニュー
- `Shift+ドラッグ` で軸を固定（移動も大きさ変更も、動かした向きの軸だけに効きます）、`Ctrl+ドラッグ` で複製

## タッチ操作

- 2 本指でつまむと拡大縮小、そのまま動かすと画面移動
- 空白を長押しすると挿入メニュー
- ダブルタップで文字入力
- ツールは画面下のドックから選びます。枠・直線・フレームは「その他」の中です

## ファイル形式

保存されるのは 1 つの JSON ファイルです。図形・レイヤー・テーマ・表示位置を含みます。画像はデータとして埋め込まれるので、画像を貼ると相応にファイルが大きくなります。

```json
{
  "format": "whiteboard-json",
  "version": 4,
  "theme": "dark",
  "layers": [{ "id": "…", "name": "レイヤー1", "visible": true, "locked": false }],
  "camera": { "x": -80, "y": -60, "s": 1 },
  "shapes": [ … ]
}
```

古い版で保存したファイルも開けます。レイヤーの記録が無いファイルは既定のレイヤーに入ります。テーマの記録が無いファイルは**深緑**で開きます（既定がダークに変わる前に保存されたものなので、図形の色も深緑のものが入っているため）。

読み込むファイルは信用しません。壊れた値や知らない種類の図形は読み飛ばし、読み飛ばした件数をステータスバーに出します。検証がすべて済んでから中身を差し替えるので、途中で失敗しても編集中の内容は壊れません。

## 制限と注意

- **上書き保存できる環境は限られます**。詳しくは上の表を参照してください
- **自動バックアップは保存の代わりではありません**。ブラウザ内の専用領域に 20 秒ごとに退避するだけで、サイトデータを削除すると一緒に消えます。通常の保存は別途行ってください
- **共同編集はできません**。1 人で使う前提の設計です
- **リポジトリを public にする必要があります**（GitHub Pages の無料枠を使う場合）。板書の内容をリポジトリに含めない運用にしてください
- 拡張機能による自動的な配色の反転を辞退する宣言を入れています。暗い配色で使いたい場合はアプリ内のテーマから選んでください

## テスト

`test.html` にテストページが入っています。テストの実行にビルドもインストールも要りません。`index.html` を隠した iframe で読み込み、その中で動いている関数をそのまま呼んで確かめます。

**`file://` では動きません。** ブラウザは `file://` で開いた HTML をオリジンの無い文書として扱うため、iframe の中身に触れられないからです。次のどちらかで HTTP 配信してから開いてください。

```
python -m http.server 8000
```

```
npx --yes http-server -p 8000
```

配信したら `http://localhost:8000/test.html` を開きます。合計・成功・失敗の件数が上に出て、失敗した場合は期待値と実際の値が並びます。全部緑なら通っています。

テストが読み取るのは `index.html` の末尾にある `window.__WB_TEST__` だけです。ここは関数への参照を集めているだけで、アプリの動作には関わりません。

## 開発について

依存関係もビルドもありません。`index.html` を直接編集します。ファイル内は次の順に並んでいます。

1. `<style>` — 配色変数とレイアウト
2. `<body>` — 上部バー、キャンバス、ツール、各パネル、ステータスバー
3. `<script>` — 番号付きの節に分かれています（座標変換／オブジェクトモデル／Undo／描画／接続点／ガイド／テンプレート／レイヤー／テキスト編集／ポインタ操作／保存と書き出し／キーボード）

浮かせた UI のうち、ツール・ズーム・メニュー・覆いは `#wrap`（キャンバス）の**外**に置いてあります。`#wrap` は `touch-action:none` で、中に入れるとパネルがスクロールできなくなるためです。書式パネル・レイヤー・ヘルプ・挿入メニュー・復元バーは `#wrap` の中なので、`bottom` の基準が両者で違います。

手書きストロークを含むすべての図形は SVG として描画され、重なり順とレイヤーが一貫して効きます。Undo は図形配列・レイヤー・テーマをまとめたスナップショット方式です（上限 80 件）。
